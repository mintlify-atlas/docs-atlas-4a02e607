## Getting started

<Steps>
  <Step title="Understand the architecture">
    Read the [Architecture Overview](/architecture-overview) to learn how Verse (engine), RimWorld (game), and the supporting namespaces layer on top of each other.
  </Step>
  <Step title="Explore the Def system">
    Nearly all game content is data-driven through the [Def system](/verse/things-and-defs). Understanding `Def`, `ThingDef`, and `DefDatabase<T>` is the key to reading any RimWorld code.
  </Step>
  <Step title="Browse Pawn internals">
    The [Pawn class](/pawns/pawn-class) is the central actor in RimWorld. It holds trackers for health, needs, skills, jobs, equipment, and more — start here to understand colonist behavior.
  </Step>
  <Step title="Write your first mod">
    Head to the [Modding Reference](/modding/defs-and-defof) to learn how to define new Defs, attach ThingComps, write XML patches, and extend the game with DefModExtensions.
  </Step>
</Steps>
